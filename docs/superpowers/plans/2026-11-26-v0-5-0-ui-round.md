## 键盘真相（本轮根因定性）

- Expo SDK 58 默认 edge-to-edge：Android `adjustResize` 失效，`KeyboardAvoidingView`
  的 behavior 在 Android 上拿不到 resize 后的布局 → 键盘直接覆盖。
- 结论：**不依赖 windowSoftInputMode**，用 `Keyboard` 事件监听器驱动的容器
  （keyboardDidShow/Hide + iOS keyboardWillShow），把表单 bottom/translateY 显式
  抬到 `keyboard + safe-area` 之上；活动输入框 `scrollIntoView` 二次保险；
  提交主钮恒在键盘上方。Android 需在 app.json 设
  `android.softwareKeyboardLayoutMode: "pan"`（edge-to-edge 下唯一能拿到真实
  keyboardHeight 且系统不改布局的模式；resize 模式在 SDK 54+ edge-to-edge 下
  失效即本案根因），由控制器落 app.json——B 在结单里给出最终建议，若有出入以
  RN/Expo 文档实证为准并在契约测试里锁住所选项。
